# Interfolio

> Interfolio is a Faculty Information System (an Elsevier product) for managing the full academic faculty lifecycle — recruiting and hiring (Faculty Search), activity reporting (Faculty180 / Faculty Activity Reporting), review, promotion and tenure (RPT), lifecycle management, faculty web profiles, and the Dossier application service. It exposes REST and GraphQL APIs secured with an HMAC public/private key mechanism scoped by tenant.

## APIs

- [Faculty180 Faculty Activity Reporting API](https://www.faculty180.com/api_docs): RESTful API for faculty listings, courses taught, SCP activity attachments, faculty vita, and public faculty activity search. Base host https://faculty180.interfolio.com. HMAC-signed (INTF public:signature, Timestamp, INTF-DatabaseID).
- [Interfolio Core, Search & RPT API](https://interfolio.com/data/): REST (https://logic.interfolio.com) + GraphQL (https://caasbox.interfolio.com) for core Units, Faculty Search, and Review-Promotion-Tenure data. HMAC public/private key scoped by tenantId.
